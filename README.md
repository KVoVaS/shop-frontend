# TechShop — интернет-магазин на React + TypeScript

Курсовой проект: SPA-интернет-магазин на React 18, TypeScript, Vite, Redux Toolkit, RTK Query.
REST API эмулируется через MSW (включён только в режиме разработки).

## Требования

- Node.js 20.19+ (рекомендуется LTS 22 или 24)
- npm (идёт в комплекте с Node.js)
- Git

Проверка версий:

```bash
node -v
npm -v
```

## Как запустить

1. Клонировать репозиторий
```bash
git clone https://github.com/KVoVaS/shop-frontend.git
```

2. Перейти в папку проекта
```bash
cd shop-frontend
```

3. Установить зависимости
```bash
npm install
```

4. Запустить dev-сервер
```bash
npm run dev
```

Открыть в браузере: http://localhost:5173
